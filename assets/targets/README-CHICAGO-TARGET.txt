APTA TRANSform 2026 — CHICAGO MINDAR TARGET
============================================

Add the compiled Chicago two-sided MindAR database here:

assets/targets/apta-transform-2026-chicago-two-sided.mind

Recommended compile order:

Target 0 = APTA TRANSform 2026 Chicago side
Target 1 = IDIS side for the Chicago coin

IMPORTANT
---------
If the IDIS artwork is pixel-for-pixel identical to the IDIS side of another physical coin,
MindAR cannot use that image alone to determine which physical coin it came from.

This folder is intentionally not referenced by the live app yet. Add/verify the .mind file first,
then wire Chicago into the scanner so missing assets cannot affect the current Atlanta experience.
